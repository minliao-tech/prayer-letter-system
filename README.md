# 教會代禱信管理系統 V1

第一版功能：
- A/B/C/D 每週輪值（以 2026-09-11 D 組為基準）
- 部門/子單位階層式選擇
- 代禱事項不限項數
- SQLite 收件資料庫
- 管理後台：已繳/未繳、編輯、確認
- 一鍵輸出 Word (.docx)
- 手機版基本響應式介面

## 安裝
需要 Python 3.10+。

```bash
pip install -r requirements.txt
python app.py
```

瀏覽器開啟：
http://127.0.0.1:5000

## V1 注意
這是可運行原型。正式上線前建議補：
1. 管理員登入與部門填寫權限
2. HTTPS、備份、正式資料庫
3. 截止時間/催繳通知
4. 依 A/B/C/D 各組實際 Word 樣板精準套版
5. 寄信或 Gmail 串接
